# CMMS — Hospitality Facility Management

The complete Puter.js application, preventive-maintenance calendar, tests and manual live in [`cmms/`](cmms/).

- [Start guide](cmms/README.md)
- [Complete user manual](cmms/USER_MANUAL.md)
- [Source](cmms/src/main.js)
- [PM scheduling engine](cmms/src/core.js)

Start locally: `cd cmms && npm ci && npm run dev`. Verify with `npm run check`.

**Architecture:** Single-account Puter KV cloud storage; not a centralized multi-user enterprise CMMS. Read the manual before operational use.
